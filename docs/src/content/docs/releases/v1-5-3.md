# Release v1.5.3

**Released**: 2026-10-02

## 🐛 Bug fixes

### Desktop startup: resilient Prisma CLI resolution

- Removed single-path Prisma CLI assumption (`backend/node_modules/prisma/build/index.js`) in both:
  - Tauri runtime bootstrap (`src-tauri/src/lib.rs`)
  - backend bootstrap migration path (`backend/src/main.ts`)
- Runtime now resolves Prisma CLI from package metadata (`package.json` bin) with safe fallbacks.

### Desktop seed reliability on production startup

- Seed failures are now startup-blocking (no silent warning-only continuation).
- Production startup now auto-heals reference data **only when** `asset_types` is empty.
- `tauri:install` post-install checks now fail if seeded `asset_types` are missing.

## 🌱 Seed data improvements

- Development seed now includes two additional demo assets:
  - `MSCI World ETF` (`STOCKS`)
  - `Bitcoin Wallet` (`CRYPTO`)
- Added snapshot history generation for both assets.
- Updated seeded portfolio baseline snapshot value from `239200.0` to `245800.0`.
