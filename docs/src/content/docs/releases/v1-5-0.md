# Release v1.5.0

**Released**: 2026-10-02

## ✨ Improvements

### Financing scenario assumptions and comparison

- Added **Insurance Fee Assumption** (`% of purchase price`) to financing scenarios.
- Insurance fee is applied as a **one-time upfront fee** to loan options only (`CUSTOM_DOWN_PAYMENT`, `FULL`).
- Financing comparison now uses a **single matrix table** (metrics as rows, options as columns) instead of repeated option cards.
- Added a reserve-warning comparison row that keeps “Emergency reserve is at risk…” visible per option.
- Added insurance fee row to the comparison metrics.

### Better defaults and glossary clarity

- New scenario defaults are now:
  - Annual Loan Rate: `6%`
  - Insurance Fee: `0.5%`
  - Standard Loan Duration: `5 years`
- Added a financing glossary section on the page for:
  - **Monthly Available Amount (EUR)**
  - **Funding Shortfall**

### API and compatibility

- Extended financing scenario request/response contracts with insurance fields.
- Extended calculator output with per-option `insuranceFee`.
- Legacy saved scenarios without insurance input remain compatible through default normalization (`0`).
- Updated Bruno examples for financing create/update payloads.

## 🧪 Testing

- **Backend e2e**: `npm run test:e2e` passed (73 tests).
