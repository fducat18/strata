# Release v1.5.2

**Released**: 2026-10-02

## 🐛 Bug fixes

### Desktop startup: Prisma migrate could fail with `os error 2`

- Hardened Tauri desktop Node resolution so GUI launches are no longer dependent on a narrow hardcoded PATH assumption.
- Runtime now resolves Node in this order:
  1. Build-time detected absolute Node path (`STRATA_NODE_PATH`)
  2. Common system paths (`/opt/homebrew/bin/node`, `/usr/local/bin/node`, `/usr/bin/node`)
  3. User-local path (`~/.local/bin/node`)
  4. Bare `node` as last-resort fallback
- Added explicit Prisma CLI path guard for `backend/node_modules/prisma/build/index.js` with actionable error text when missing.
- Improved migrate/seed/backend startup error messages to include the exact Node binary attempted.

### Documentation parity

- Updated desktop app docs to reflect actual Node resolution behavior.
- Added targeted troubleshooting guidance for `could not run prisma migrate`.
