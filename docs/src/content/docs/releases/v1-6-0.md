# Release v1.6.0

**Released**: 2026-10-23

## ✨ New features

### Net Worth History series visibility

- Toggle individual Assets and Liabilities series in Net Worth mode.
- Toggle Group, Type, and Category series independently, including multiple visible categories.
- Automatically rescale the chart to the currently visible series.

## ⚙️ Release tooling

- Keep the `strata-desktop` entry in `src-tauri/Cargo.lock` synchronized with release manifests.
- Add an isolated release-script regression test to CI.
- Clarify release gates, clean-worktree requirements, and version-sync instructions.
