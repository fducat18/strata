# Release v1.4.0

**Released**: 2026-09-18

## ✨ Improvements

### Sortable asset list columns

The Assets page now supports one-click ascending and descending sorting from the arrow in the **Name**, **Type**, **Current Value**, **Categories**, **Tags**, and **Status** column headers.

- Name is sorted A–Z by default.
- Text columns use case-insensitive alphabetical ordering.
- Current Value uses decimal-safe numeric ordering.
- Empty categories/tags and missing current values remain last.
- Sort direction is shown with an accessible chevron indicator and resets on a fresh page visit.
