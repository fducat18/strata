# Release v1.6.2

## Backup import

- Raise the global JSON request-body limit from the Express default of 100 KiB
  to 10 MiB, so large backups restore from the Settings page instead of
  failing with HTTP 413 "Payload Too Large".
- Accept the optional ISO 8601 `exportedAt` metadata that current exports
  include; restore validates it when present and older backups without it
  remain valid.
- Add regression coverage proving an exported payload larger than 164 KiB
  restores successfully, while malformed timestamps and unsupported schema
  versions are still rejected.

## Process

- Document that a semver release happens only after the change lands on
  `main` and CI is green — never from a local feature branch.
