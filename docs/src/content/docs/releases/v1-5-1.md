# Release v1.5.1

**Released**: 2026-10-02

## ✨ Improvements

### Safer and clearer seed behavior

- Split Prisma seed flow into explicit profiles:
  - **Development (`strata-dev.db`)** seeds full demo data.
  - **Production (`strata.db`)** seeds reference data only (asset types + categories).
- Added regression coverage for profile behavior in backend e2e (`seed-profile.e2e-spec.ts`).
- Updated Docker/Tauri/test seed wiring so the right profile is selected consistently.

### Dev-data hygiene for e2e residue

- Added manual one-shot cleanup command for leaked test artifacts in dev DB:
  - `npm run devdb:clean-e2e` (root)
  - internally runs backend `cleanup:test-data`
- Cleanup targets known test prefixes (`Test Asset`, `E2E Category`, `Test Category`, `e2e-tag`, `test-tag`) with safe delete ordering and a dev-DB guard.
- Hardened frontend asset CRUD e2e to delete created test assets after each test.

### Demo snapshot history enrichment

- Replaced short demo snapshot seed with a deterministic **10-year history** at **3 points/year**.
- Non-loan demo assets now include both upward and downward variation.
- Loan demo asset history is strictly declining.
- Existing demo assets are now backfilled when running dev seed manually.

### Frontend dependency refresh

- Upgraded frontend dependencies to current stable versions (including Astro and React ecosystem updates).
- Adjusted Vitest config/test setup and Playwright assertions to keep full test suites green after upgrade.

### Documentation parity

- Updated setup/runtime/config docs to include:
  - `npm run tauri:install` operational path
  - seed-profile behavior
  - dev cleanup command usage
  - demo-history backfill guidance

## 🧪 Testing
